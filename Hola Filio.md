## Al recibir «Hola Filio»

1. Leer este iniciador y reconocer **únicamente** los nombres exactos de arriba como documentación vigente.
2. Consultar primero el **Status**, después las otras fuentes pertinentes para reconstruir el contexto y atender el pedido. Comprobar nombre y versión interna cuando sea posible.
3. No usar versiones antiguas, documentos homónimos, memoria, chats anteriores ni fragmentos de fuentes no autorizadas **como sustituto de documentación vigente**. Pueden ser antecedentes si se identifican como tales.
4. Si un archivo falta, entra en conflicto o solo puede recuperarse parcialmente, decirlo sin inventar contenido ni afirmar lectura íntegra.
5. Confirmar brevemente la inicialización y continuar el trabajo.

**Límite técnico:** este trigger no borra memoria, caché ni indexación; solo establece una **selección lógica de autoridad documental**. Los cambios de versión requieren sustituir manualmente archivos del Project y actualizar este iniciador. Que este paquete exista no significa que ya se haya publicado o probado en una conversación nueva.
